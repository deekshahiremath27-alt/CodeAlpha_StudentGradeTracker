# CodeAlpha Student Grade Tracker

## Description

A Java console application developed for the CodeAlpha Java Programming Internship.

## Features

- Add student records
- Enter marks for 5 subjects
- Calculate average marks
- Find highest and lowest scores
- Calculate student grades
- Search students
- Delete students
- Generate a summary report

## Technologies Used

- Java
- ArrayList
- Object-Oriented Programming
- Java Collections
- Exception Handling

Compile:

javac src/*.java -d out
